# Glossary
:::{glossary}

[NoC](https://en.wikipedia.org/wiki/Network_on_a_chip)
: Network-on-Chip, a communication architecture that integrates multiple processing elements into a single chip.

[ODE](https://en.wikipedia.org/wiki/Ordinary_differential_equation)
: Ordinary Differential Equation, a mathematical equation that describes how a function changes with respect to one or more variables.

[SNN](https://en.wikipedia.org/wiki/Spiking_neural_network)
: Spiking Neural Network, a type of artificial neural network that more closely mimics the behavior of biological neurons by using discrete spikes for communication.

:::
